# 🚀 Персональный сайт-портфолио + Сервис сокращения ссылок

Добро пожаловать в мой проект! Это не просто очередной "Hello World", а **полноценная платформа**, которая объединяет мое портфолио и полезный сервис. Проект развернут в продакшене и доступен по адресу: [vorobevaqa.ru](https://vorobevaqa.ru)

---

## 📖 О проекте

Проект представляет собой **монолитное Spring Boot приложение**, которое выполняет две функции:

1.  **Сайт-визитка / Портфолио**  
    Персональная страница с информацией обо мне, моих навыках и проектах. Использует Thymeleaf для рендеринга HTML-шаблонов.

2.  **Сервис сокращения ссылок (URL Shortener)**  
    Позволяет пользователям создавать короткие ссылки и переходить по ним. Включает подсчет количества переходов и базовую статистику.

### 🛠️ Ключевые возможности

*   **Создание коротких ссылок**: API для сокращения длинных URL.
*   **Редирект**: Автоматическое перенаправление по короткому коду.
*   **Статистика**: Просмотр количества переходов по ссылке.
*   **Адаптивный дизайн**: Сайт корректно отображается на мобильных устройствах и ПК.

## 🏗️ Технологический стек

### Backend
*   **Java 17** — язык программирования.
*   **Spring Boot 3.x** — фреймворк.
*   **Spring Data JPA (Hibernate)** — ORM для работы с базой данных.
*   **PostgreSQL** — основная база данных (в продакшене).
*   **H2 Database** — in-memory БД для локальной разработки и тестов.
*   **Maven** — сборка и управление зависимостями.

### Frontend
*   **Thymeleaf** — шаблонизатор для HTML-страниц.
*   **CSS3** — кастомные стили (адаптивная верстка, анимации).
*   **JavaScript (Vanilla)** — интерактивность на странице сокращения ссылок.

### DevOps & Инфраструктура
*   **Docker** — контейнеризация приложения и базы данных.
*   **Docker Compose** — оркестрация многоконтейнерного приложения.
*   **Nginx** — реверс-прокси и SSL-терминация (HTTPS).
*   **GitHub Actions** — CI/CD пайплайн (автоматическая сборка, тестирование и деплой).
*   **Docker Hub** — хранение готовых Docker-образов.
*   **Let's Encrypt** — SSL-сертификат для защиты трафика.

## 🚀 Деплой и CI/CD

Проект использует **GitHub Actions** для автоматизации процессов:

1.  **Сборка и тестирование**: `mvn clean verify` запускается при каждом пуше в `master`.
2.  **Сборка Docker-образа**: Образ собирается и пушится в Docker Hub (`andreyvorobevaqa/ci-cd-maven-project`).
3.  **Автоматический деплой**: При успешной сборке пайплайн подключается к VDS через SSH, скачивает новый образ и перезапускает контейнеры через `docker compose`.
